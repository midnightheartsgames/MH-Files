1.0.0-rc.7 на Windows. `1.0.0` выйдет после полной проверки на Windows
([PLAN.md §7](https://github.com/midnightheartsgames/MH-Files/blob/main/PLAN.md#7-проверка-на-windows-обязательно-перед-10)).

## Что скачать

* `MH-Files-1.0.0-rc.8-setup.exe` — установка в `%LOCALAPPDATA%\Programs\MH Files`, без прав
  администратора. Поверх 1.0.0-rc.7 ставится как обновление: настройки и вкладки на месте,
  прежние настройки — копией в `backup\1.0.0-rc.7`.
* `MH-Files-1.0.0-rc.8-portable.zip` — распаковать куда угодно: настройки и индекс хранятся в
  папке `data` рядом с exe.
* `SHA256SUMS.txt` — контрольные суммы.

Установщик пока не подписан: SmartScreen при первом запуске предупредит — «Подробнее ›
Выполнить в любом случае».

## Исправлено

* **Контекстное меню выходит за окно программы.** Большое меню (свои команды и пункты
  Windows) больше не обрезается краем окна: меню и подменю открываются своими окнами
  поверх остальных, как в Проводнике. У правого края монитора меню открывается влево, у
  нижнего — вверх.
* **Меню компактнее**: шрифт мельче, строки ниже — во всех контекстных меню.
* **Бросок файлов в zip** — на файл архива и в открытый архив — давал ошибку «Неверно задано
  имя папки». Теперь MH Files дописывает zip сам: работает с копией архива и подменяет его
  только в конце, прежние файлы архива не трогает. Занятое имя не перезаписывается — новый
  файл ложится рядом с номером («отчёт (2).docx»), папка с тем же именем дополняется.

## Новое

* **Корзина внутри MH Files.** «Корзина» в боковой панели открывается вкладкой: удалённое со
  всех дисков, откуда и когда удалено. «Восстановить» возвращает на место, Delete — «Удалить
  насовсем» с вопросом, «Очистить корзину» — в меню. Вкладка обновляется сама.
* **Закрытие последней вкладки** открывает на её месте «Этот компьютер»; Ctrl+Shift+T
  возвращает закрытую.

## Известно

* Всё, что работает только в Windows, проверено сборкой и тестами на Windows в CI; ручная
  проверка — §7, пункты 66 и 93–96.
* Меню и подменю — отдельные окна: при первом открытии меню нового вида его размер
  подстраивается со второго кадра.
* В zip нельзя заменить файл с тем же именем — только положить рядом с номером.
