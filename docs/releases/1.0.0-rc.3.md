Третий выпуск-кандидат MH Files 1.0: пункты меню Проводника прямо в своём контекстном меню,
масштаб колесом мыши и мелкие улучшения. `1.0.0` выйдет после полной проверки на Windows
([PLAN.md §7](https://github.com/midnightheartsgames/MH-Files/blob/main/PLAN.md#7-проверка-на-windows-обязательно-перед-10)).

## Что скачать

* `MH-Files-1.0.0-rc.3-setup.exe` — установка в `%LOCALAPPDATA%\Programs\MH Files`, без прав
  администратора. Поверх 1.0.0-rc.2 ставится как обновление: настройки и вкладки на месте,
  прежние настройки — копией в `backup\1.0.0-rc.2`.
* `MH-Files-1.0.0-rc.3-portable.zip` — распаковать куда угодно: настройки и индекс хранятся в
  папке `data` рядом с exe.
* `SHA256SUMS.txt` — контрольные суммы.

Установщик пока не подписан: SmartScreen при первом запуске предупредит — «Подробнее ›
Выполнить в любом случае».

## Новое

* **Меню Проводника внутри своего**, как в OneCommander: под командами MH Files — пункты
  Windows и программ (7-Zip, Git, PowerToys, VS Code…) с их значками, подменю «Отправить»,
  «Открыть с помощью», «Создать». Своё меню открывается сразу, пункты Windows появляются
  следом, без повторов того, что у MH Files уже есть. Работает в меню файлов, пустого места
  папки и боковой панели. С Shift — расширенные пункты, как в Проводнике. Выключается в
  «Настройки › Файлы › Пункты меню Windows»; полное меню Windows — по-прежнему Shift+F10.
* **Масштаб Ctrl+колесом мыши** (и щипком на тачпаде) — шаг на щелчок колеса, как
  Ctrl+Plus/Minus.
* **Диски подписаны «C: Локальный диск»** — буква тома первой.
* **Кнопка настроек** (шестерёнка) в строке состояния и свой значок у окна настроек на панели
  задач.

## Известно

* Пункты, которые программа рисует в меню сама, и такие же значки во встроенном меню не
  показываются — они есть в полном меню Windows (Shift+F10).
* Всё, что работает только в Windows, проверено сборкой и тестами на Windows в CI; ручная
  проверка — §7, пункты 53–72.
