Пятый выпуск-кандидат MH Files 1.0: исправления и доработки по итогам ручной проверки
1.0.0-rc.4 на Windows. `1.0.0` выйдет после полной проверки на Windows
([PLAN.md §7](https://github.com/midnightheartsgames/MH-Files/blob/main/PLAN.md#7-проверка-на-windows-обязательно-перед-10)).

## Что скачать

* `MH-Files-1.0.0-rc.5-setup.exe` — установка в `%LOCALAPPDATA%\Programs\MH Files`, без прав
  администратора. Поверх 1.0.0-rc.4 ставится как обновление: настройки и вкладки на месте,
  прежние настройки — копией в `backup\1.0.0-rc.4`.
* `MH-Files-1.0.0-rc.5-portable.zip` — распаковать куда угодно: настройки и индекс хранятся в
  папке `data` рядом с exe.
* `SHA256SUMS.txt` — контрольные суммы.

Установщик пока не подписан: SmartScreen при первом запуске предупредит — «Подробнее ›
Выполнить в любом случае».

## Исправлено

* **Быстрый просмотр темнел целиком** и закрывался от щелчка в любом месте — до перезапуска
  программы. Случалось после того, как просмотр закрыли щелчком по затемнению.
* **Исключения поиска по дискам** не убирали то, что уже было в индексе: файлы из
  исключённой `C:\Windows` оставались в выдаче. Теперь исключённое пропадает после
  «Применить» и не возвращается после перезапуска. Путь, набранный в поле, но не добавленный
  кнопкой, раньше молча терялся — теперь добавляется по Enter и при «Применить»; путь в
  кавычках («Копировать как путь» Проводника) тоже подходит.
* **Флешка оставалась в поиске** после того, как её вынули. Теперь отключённый диск сразу
  уходит из выдачи; USB-диски, которые Windows называет «несъёмными», и карты памяти
  считаются съёмными (значок, галочка «Съёмные диски»); другая флешка на той же букве не
  показывает файлы прежней; кардридер без карты в поиске не участвует.

## Новое

* **Флешка появляется сразу** — в боковой панели и «Этом компьютере» через секунду после
  подключения, без перезапуска.
* **Пункты Windows в контекстном меню — почти сразу**: собираются уже при нажатии правой
  кнопки, а подменю вроде «Отправить ▸» дозаполняются следом. Первое меню после запуска не
  ждёт загрузки расширений.
* **Переименование вторым щелчком** по имени выделенного файла, как в Проводнике: в таблице,
  плитках и колонках. Двойной щелчок по-прежнему открывает. Двойной щелчок теперь меряется
  по настройке Windows.
* **SVG картинкой** в Инспекторе, быстром просмотре и эскизах плиток (и без PowerToys).
  Ссылки на файлы и сетевые пути внутри SVG не открываются.

## Известно

* Всё, что работает только в Windows, проверено сборкой и тестами на Windows в CI; ручная
  проверка — §7, пункты 73–78 (и прежние 53–72).
* Пока флешку отслеживает индекс поиска, Windows может не дать «Безопасно извлечь» —
  проверяется.
