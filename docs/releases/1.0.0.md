Первый выпуск MH Files — файлового менеджера для Windows 10/11 на Rust: быстрые панели и
вкладки, поиск по всем дискам за миллисекунды, архивы как папки, дубликаты и сортировщик, в
визуальном языке MH. Один `.exe`, без Electron/WebView и фоновых служб.

Выпуск прошёл полную ручную проверку на Windows
([PLAN.md §7](https://github.com/midnightheartsgames/MH-Files/blob/main/PLAN.md#7-проверка-на-windows-обязательно-перед-10))
по восьми выпускам-кандидатам; по сравнению с 1.0.0-rc.8 код не менялся.

## Что скачать

* `MH-Files-1.0.0-setup.exe` — установка в `%LOCALAPPDATA%\Programs\MH Files`, без прав
  администратора. Поверх любого выпуска-кандидата ставится как обновление: настройки и
  вкладки на месте, прежние настройки — копией в `backup\<прежняя версия>`.
* `MH-Files-1.0.0-portable.zip` — распаковать куда угодно, хоть на флешку: настройки и индекс
  хранятся в папке `data` рядом с exe.
* `SHA256SUMS.txt` — контрольные суммы.

Установщик пока не подписан: SmartScreen при первом запуске предупредит — «Подробнее ›
Выполнить в любом случае».

## Что внутри

* **Окно**: панели делятся в любую сторону, у каждой вкладки; таблица, плитки с эскизами и
  «Колонки»; боковая панель с дисками, корзиной, избранным и сохранёнными поисками; палитра
  команд, GoTo, фильтр; свой заголовок окна со Snap Layouts; все клавиши настраиваются.
* **Файлы**: копирование, перемещение и корзина через Windows Shell, своя панель операций
  с паузой и отменой, «Отменить» (Ctrl+Z); перетаскивание с Проводником в обе стороны;
  контекстное меню с пунктами Проводника и программ; пакетное переименование; цветные
  метки; корзина вкладкой с «Восстановить»; размеры папок сразу.
* **Просмотр**: Инспектор и быстрый просмотр — картинки, SVG, текст, PDF, шрифты, документы
  Office, видео и музыка с эквалайзером; эскизы всех типов, которые знает Windows.
* **Поиск**: по всем дискам из индекса имён (Ctrl+E) с языком запросов, во вложенных папках
  и по содержимому файлов.
* **Архивы**: zip, 7z, rar и архив в архиве как папки; извлечение; дописывание в zip.
* **Дубликаты и сортировщик** MH Sort: отметка лишних копий, жёсткие ссылки; раскладка папок
  по категориям с правилами, расписанием и отменой.
* **Windows**: одна копия программы, «Открыть в MH Files» в меню Проводника, открытие папок
  в MH Files вместо Проводника, командная строка, проверка обновлений.

Подробно — в [README](https://github.com/midnightheartsgames/MH-Files#readme).

## Известно

* В zip нельзя заменить файл с тем же именем — новый ложится рядом с номером; запись в 7z
  не поддерживается.
* Метка цвета привязана к пути: файл, переименованный в Проводнике, метку теряет.
* При перетаскивании из Проводника значок у курсора всегда «Копировать», даже если файлы
  будут перемещены: что сделать, MH Files решает при броске.
