## Что скачать

* `MH-Files-1.0.0-rc.2-setup.exe` — установка в `%LOCALAPPDATA%\Programs\MH Files`, без прав
  администратора. Поверх 1.0.0-rc.1 ставится как обновление: настройки и вкладки на месте,
  прежние настройки — копией в `backup\1.0.0-rc.1`.
* `MH-Files-1.0.0-rc.2-portable.zip` — распаковать куда угодно: настройки и индекс хранятся в
  папке `data` рядом с exe.
* `SHA256SUMS.txt` — контрольные суммы.

Установщик пока не подписан: SmartScreen при первом запуске предупредит — «Подробнее ›
Выполнить в любом случае». Сборка уже умеет подписываться, как только появится сертификат.

## Новое

**Windows и Проводник**

* «Проверить обновления» в «Настройки › О программе» — один запрос к GitHub Releases, сама
  программа в сеть не ходит.
* «Открывать папки в MH Files» — двойной щелчок по папке на рабочем столе и в других
  программах открывает MH Files. `Win+E` и «Панель управления» остаются за Проводником.
* MH Files в «Открыть с помощью» для zip, 7z и rar: архив открывается как папка.
* Snap Layouts Windows 11 у своего заголовка окна, скруглённые углы.
* Перетаскивание правой кнопкой: «Копировать сюда / Переместить сюда / Создать ярлыки»;
  наружу — меню самого Проводника.
* Ctrl+Z возвращает удалённое в корзину.
* Зависшее расширение в меню Windows больше не оставляет без меню: через 6 секунд — меню без
  сторонних пунктов.

**Архивы и просмотр**

* Архив в архиве (zip в zip, 7z в zip) открывается как папка.
* rar — через установленный 7-Zip или `tar.exe` Windows 11.
* Файлы можно бросить в zip — его дописывает Проводник.
* Видео и музыка играют прямо в быстром просмотре (пробел): Enter — пауза, Shift+стрелки —
  перемотка, ползунки времени и громкости.

**Поиск и дубликаты**

* Поиск по содержимому текстовых файлов — Ctrl+Alt+F (`договор аренды *.txt`).
* Съёмные и сетевые диски в поиске по дискам — по галочкам; флешка подхватывается сама.
* Запущенный от администратора MH Files строит первый индекс диска из MFT за секунды.
* Дубликаты: порог размера, исключения (`node_modules`, `*.tmp`, папки), «Жёсткие ссылки
  вместо копий» — копии остаются на местах, но перестают занимать место.

**Сортировщик**

* Категории правятся прямо в «Настройки › Сортировка».
* Правила по дате и размеру: «старше года — в Архив», «больше 4 ГБ — в Большие».
* Папку можно раскладывать по расписанию (каждый час … раз в неделю), пока программа
  открыта; каждая такая сортировка отменяется Ctrl+Z.
* Файл в плане можно перетащить на другую категорию.
