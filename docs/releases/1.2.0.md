MH Files 1.2: поиск по смыслу на EmbeddingGemma 2 — файлы находятся по описанию того, что в
них, а не только по имени.

## Что скачать

* `MH-Files-1.2.0-setup.exe` — установка в `%LOCALAPPDATA%\Programs\MH Files`, без прав
  администратора. Поверх 1.1 ставится как обновление: настройки и вкладки на месте,
  прежние настройки — копией в `backup\1.1.0`.
* `MH-Files-1.2.0-portable.zip` — распаковать куда угодно, хоть на флешку: настройки, индекс и
  модель хранятся в папке `data` рядом с exe.
* `SHA256SUMS.txt` — контрольные суммы.

Установщик пока не подписан: SmartScreen при первом запуске предупредит — «Подробнее ›
Выполнить в любом случае».

## Новое

* **Поиск по смыслу** (Ctrl+Shift+Space, «По смыслу» в строке поиска или пункт боковой
  панели). Опишите своими словами, что ищете: «кошка на диване» найдёт фотографию кошки,
  «договор аренды» — скан договора, «презентация о продажах» — нужный pptx, даже если файлы
  называются `IMG_0412.jpg` и `Новая презентация (3).pptx`.
  * Модель — [EmbeddingGemma 2](https://huggingface.co/google/embeddinggemma-2) от Google
    DeepMind: текст, картинки и звук в одном пространстве смыслов; модель многоязычная и
    понимает русский.
  * Понимает текст и код, Word, Excel, PowerPoint, OpenDocument, первые страницы PDF,
    картинки (HEIC и RAW — если в Windows стоят кодеки), кадр видео и первые 30 секунд
    записей MP3 и WAV; остальные файлы — по имени.
  * Категории под полем запроса сужают выдачу: «Изображения», «Документы», «Аудио»…
  * У файла под курсором видно, чем он подошёл: «по изображению», «по странице 2» или отрывок
    текста, и насколько похож.
  * Переключатель «По имени / По смыслу» сохраняет набранный текст: можно искать то так, то
    так.
* **Всё на этом компьютере.** Файлы никуда не отправляются: модель работает в отдельном
  процессе `llama-server` (llama.cpp) рядом с MH Files и закрывается вместе с ним.
* **Включается в «Настройки › Поиск по смыслу».** При включении скачивается около гигабайта:
  модель [`unsloth/embeddinggemma-2-GGUF`](https://huggingface.co/unsloth/embeddinggemma-2-GGUF)
  (Q8_0) с Hugging Face и сборка llama.cpp с Vulkan с GitHub. Там же — какие папки
  индексировать (по умолчанию Рабочий стол, Документы, Загрузки, Изображения, Видео и
  Музыка), исключения, что понимать (картинки, документы, звук), видеокарта, квантование
  модели и свой `llama-server`.
* Видеокарта считает через Vulkan; если драйвер отказал, модель сама переходит на процессор.
  Индексация идёт в фоне с пониженным приоритетом, на половине ядер. Через пять минут без
  поиска модель уходит из памяти, первый поиск после этого ждёт её загрузку пару секунд.
* Пересчитывается только изменённое: папки пересматриваются раз в полчаса и по команде
  «Пересканировать папки поиска по смыслу»; удалённые файлы уходят из индекса.
* При удалении программы удаляется и скачанная модель (`%LOCALAPPDATA%\MH Files\semantic`).

## Известно

* Поиск по смыслу проверен с поддельной моделью; первые отзывы с настоящей моделью на
  Windows — особенно о скорости индексации картинок на процессоре — очень пригодятся.
* Звук понимается по первым 30 секундам, видео — по одному кадру (эскизу Windows).
* Смена того, что понимать (картинки, документы, звук) или модели строит индекс заново.
* В zip нельзя заменить файл с тем же именем — новый ложится рядом с номером; запись в 7z
  не поддерживается.
* Метка цвета привязана к пути: файл, переименованный в Проводнике, метку теряет.
