MH Files 1.3: автотеги — что изображено на картинках и кадрах видео, словами, прямо в
списке файлов и в Инспекторе.

## Что скачать

* `MH-Files-1.3.0-setup.exe` — установка в `%LOCALAPPDATA%\Programs\MH Files`, без прав
  администратора. Поверх 1.2 ставится как обновление: настройки и вкладки на месте,
  прежние настройки — копией в `backup\1.2.4`.
* `MH-Files-1.3.0-portable.zip` — распаковать куда угодно, хоть на флешку: настройки, индекс и
  модели хранятся в папке `data` рядом с exe.
* `SHA256SUMS.txt` — контрольные суммы.

Установщик пока не подписан: SmartScreen при первом запуске предупредит — «Подробнее ›
Выполнить в любом случае».

## Новое

* **Автотеги.** Модель смотрит на картинку (или кадр видео) и подписывает, что на ней:
  `cat, sleeping, bed, remote control`, `1girl, long hair, outdoors, school uniform`,
  персонажей аниме и игр. Около 10 800 тегов Danbooru, по-английски.
  * **Столбец «Теги»** в таблице — после «Размер»: самые уверенные теги через запятую. Ширина
    тянется за левую границу столбца; в узкой панели он прячется первым.
  * **Раздел «Теги» в Инспекторе**: все теги, персонажи — цветом акцента, у каждого —
    уверенность во всплывающей подсказке; щелчок по тегу копирует его, «Копировать» — все
    теги через запятую. Там же рейтинг: обычный, чувствительный, сомнительный, откровенный.
  * Теги считаются сначала у видимых файлов, потом у остальных картинок и видео открытой
    папки — в фоне, с пониженным приоритетом. Посчитанное запоминается: второй раз файл не
    смотрится, пока не изменится.
* **Модель — WD Tagger v3** от SmilingWolf (Apache 2.0), на выбор:
  [EVA02-Large](https://huggingface.co/SmilingWolf/wd-eva02-large-tagger-v3) — точнее всего
  (1,3 ГБ, по умолчанию), [SwinV2](https://huggingface.co/SmilingWolf/wd-swinv2-tagger-v3) —
  втрое быстрее (470 МБ), [ViT](https://huggingface.co/SmilingWolf/wd-vit-tagger-v3) —
  быстрее всего (380 МБ). Картинка на процессоре — от секунды до нескольких, смотря по модели
  и числу ядер.
* **Всё на этом компьютере.** Файлы никуда не отправляются: модель работает в отдельном
  процессе (тот же `MH-Files.exe` без окна) на [ONNX Runtime](https://github.com/microsoft/onnxruntime)
  и закрывается вместе с MH Files; через пять минут без дела уходит из памяти.
* **Включается в «Настройки › Автотеги».** При включении скачиваются модель с Hugging Face и
  ONNX Runtime 1.31 с GitHub (80 МБ архив, из него берутся две библиотеки). Там же — модель,
  пороги уверенности для тегов и персонажей (меняются без пересчёта), рейтинг, предел размера
  файла, «Пересчитать все теги», журнал помощника и свой ONNX Runtime.
* При удалении программы удаляются и скачанные модель с ONNX Runtime
  (`%LOCALAPPDATA%\MH Files\tags`).

## Известно

* `onnxruntime.dll` нужны библиотеки Microsoft Visual C++ (x64). Обычно они уже стоят; если
  нет — в настройках будет ссылка на установщик от Microsoft.
* Теги — на английском, словами Danbooru: модель училась на рисунках, но фото тоже узнаёт
  (`cat`, `car`, `food`, `outdoors`, `realistic`).
* Пока только процессор; видеокарта (DirectML) — в следующих версиях.
* Модели animetimm (например, `convnextv2_huge.dbv4-full`) закрыты входом на Hugging Face и
  выложены без ONNX — программа их не скачивает; WD Tagger v3 обучен на том же словаре
  Danbooru.
* Автотеги проверены с настоящими моделями под Linux (помощник, ONNX Runtime 1.31,
  EVA02-Large, SwinV2 и ViT); на Windows — первые отзывы очень пригодятся.
