MH Files 1.2.2: поиск по смыслу не берёт чужой старый llama.cpp.

## Что скачать

* `MH-Files-1.2.2-setup.exe` — установка в `%LOCALAPPDATA%\Programs\MH Files`, без прав
  администратора; поверх 1.2.x ставится как обновление, скачанная модель остаётся.
* `MH-Files-1.2.2-portable.zip` — распаковать куда угодно: настройки, индекс и модель хранятся
  в папке `data` рядом с exe.
* `SHA256SUMS.txt` — контрольные суммы.

## Исправлено

* **«unknown model architecture: 'gemma-embedding2'».** Если llama.cpp уже стоял в системе
  (WinGet, Scoop — то есть был в `PATH`), MH Files брал его вместо того, чтобы скачать свою
  сборку, а старый llama.cpp не знает EmbeddingGemma 2. Теперь в Windows используется только
  скачанная MH Files сборка (не старше b11452) или путь из поля «Свой llama-server»; при
  первом запуске 1.2.2 она скачается сама.
* Свой `llama-server` из настроек проверяется по номеру сборки (`--version`): слишком старый —
  понятная ошибка с номером сборки, а не «модель не загрузилась». Та же подсказка — если
  llama.cpp всё же не знает модель; лишних попыток запуска в этом случае нет.
